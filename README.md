# Python Calculator

A stylish desktop calculator application built using Python and Tkinter.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Percentage calculation
- Decimal calculations
- Clear button
- Backspace button
- Error handling
- Dark-themed graphical user interface
- Button hover effects

## Technologies Used

- Python
- Tkinter

## How to Run

1. Install Python.
2. Download this repository.
3. Open the project folder.
4. Run:

```bash
python calculator.py
